# Readr

Application de suivi de lecture personnelle, **local-first** et sans compte. Next.js 16 + React 19, déployée sur Vercel. PWA installable, bilingue EN/FR, avec des features AI (scan ISBN, citations, character cast, quiz) servies par un Cloudflare Worker.

## Documentation

- [`docs/PROJECT.md`](docs/PROJECT.md) — vue d'ensemble : ce qu'est Readr, stack, architecture, features, décisions structurantes.
- [`docs/DESIGN-SYSTEM.md`](docs/DESIGN-SYSTEM.md) — le design system (`/design-system`) : philosophie, taxonomie, contrats d'architecture, historique du refacto.

## Démarrer

```bash
npm run dev      # http://localhost:3000
```

- App : `/library` · Design system : `/design-system`
